# Events (Feature)

## TL;DR
Events are scheduled gatherings (in-person or virtual). Events can invite multiple sections. Users RSVP to events, and event activity (comments/chat) is visible in the section feed for invited sections.

## Core UX surfaces (web)
- Events listing: `/events`
- Event detail: `/events/[eventId]`
- Create/edit event: `/create-event` and `/edit-event/[eventId]`
